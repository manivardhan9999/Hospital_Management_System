# Hospital_Management_System
A Python-based Hospital Management System using Object-Oriented Programming (OOPs) to add, view, search, and delete patient records.

## About the Project
The Hospital Management System is a simple command-line application developed using Python. It helps manage patient records through basic operations.

## Features
- Add new patient records
- View all registered patients
- Search patients by patient ID
- Delete patient records
- Prevent duplicate patient IDs
- Validate required patient information

## Technologies Used
- Python 3
- Object-Oriented Programming (OOP)
- Python Lists
- Classes and Objects

## How to Run
1. Install Python 3.
2. Download this repository.
3. Open a terminal in the project folder.
4. Run the command:

   python hospital_management_system.py
